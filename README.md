🚀 Ecossistema de Aplicações e APIs em Flask (Python)

Este repositório centraliza uma coleção de projetos e APIs desenvolvidas em Python utilizando o framework Flask. O objetivo é demonstrar a construção de sistemas web robustos, englobando desde a autenticação segura de usuários e integração com bancos de dados relacionais até a criação de rotas dinâmicas, arquitetura de APIs e automações de tarefas.

📂 Projetos do Repositório

📌 Projeto 1: Sistema de Agendamento Automatizado (/agendamentos)

Este é um sistema completo de agendamento voltado para a marcação e gestão flexível de consultas e reuniões, adaptável às necessidades de qualquer tipo de negócio. A plataforma oferece portais independentes para clientes e colaboradores: enquanto os clientes realizam e acompanham os seus próprios agendamentos, a equipa interna e a administração têm controlo total sobre a agenda, permitindo gerir horários, visualizar atendimentos e organizar o fluxo diário de trabalho.

Além do fluxo tradicional de marcações, o sistema conta com uma rotina automatizada de lembretes que notifica os clientes com um dia de antecedência via WhatsApp, SMS e e-mail para reduzir a taxa de ausências. Ele também possui uma gestão dedicada para cancelamentos, onde todos os horários desmarcados são armazenados num histórico específico com rotinas focadas em entrar em contacto para oferecer novas oportunidades de reagendamento.
